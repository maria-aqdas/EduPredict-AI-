# EduPredict AI 🎓🤖

An AI-driven student performance analyzer and personalized study planner built for the **Built with Python Hackathon**.

## 🚀 Features
- **Predictive Analytics:** Uses a Machine Learning model (`RandomForestClassifier`) to predict academic risk baselines.
- **Automated Roadmaps:** Dynamically generates target actionable steps based on attendance and quiz scoring gaps.

## 🛠️ Installation & Setup

pip install pandas scikit-learn
