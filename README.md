An AI-driven student performance analyzer and personalized study planner built explicitly for the **Built with Python Hackathon**. 

EduPredict AI helps educators and students identify academic risks early and provides automated, data-driven actionable roadmaps to bridge learning gaps.

---

## 🚀 Features

* **Predictive Analytics:** Implements a Robust Machine Learning baseline using `RandomForestClassifier` to accurately predict student academic risk levels based on historical data.
* **Automated Action Roadmaps:** Dynamically generates targeted, personalized study steps by analyzing core gaps in **attendance metrics** and **quiz score performance**.
* **Data-Driven Insights:** Provides quick feedback to help prevent student burnout and academic drops before midterm evaluations.

---

## 🛠️ Tech Stack & Architecture

* **Language:** Python 3.x
* **Machine Learning:** Scikit-Learn (Random Forest)
* **Data Manipulation:** Pandas & NumPy
